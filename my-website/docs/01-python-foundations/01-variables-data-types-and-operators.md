> **Week 2 · Module 01 · Python Foundations**

Understand Python values, declare meaningful variables, and combine arithmetic, comparison, and logical operators.

## Learning objectives

By the end of this chapter, you should be able to:

- explain the purpose of variables, data types, and operators in your own words;

## How to study this chapter

1. Begin with the problem this topic solves.
2. Learn the vocabulary in the context of a small example.
3. Work through the process by hand or with a tiny dataset.
4. Implement the smallest useful version.
5. Change one input and predict the result before running it.
6. Record what worked, what failed, and why.

## Practical activity

Create a small expense calculator that accepts prices, computes a total, and reports whether the total exceeds a budget.

Before you finish, write down the input, expected output, assumptions, and at least two checks that would reveal an incorrect result.

## Common mistakes

- Ignoring indentation and unclear names.
- Copying code without tracing values.
- Testing only the happy path.
