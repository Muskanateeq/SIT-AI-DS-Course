# Class-Based Machine Learning Projects

> **Week 21 · Module 04 · Machine Learning**

Integrate the supervised and unsupervised workflow in guided portfolio projects.

## Learning objectives

By the end of this chapter, you should be able to:

- explain the purpose of class-based machine learning projects in your own words;
- recognize the main concepts and decisions involved;
- apply the topic in a focused practical activity;
- identify common mistakes and validate your work.

## Project options

1. **House Price Prediction:** define the problem, choose appropriate data or tools, build a baseline, test the result, and present limitations.
2. **Customer Segmentation:** define the problem, choose appropriate data or tools, build a baseline, test the result, and present limitations.
3. **Loan Eligibility Prediction:** define the problem, choose appropriate data or tools, build a baseline, test the result, and present limitations.
4. **Fraud Detection Model:** define the problem, choose appropriate data or tools, build a baseline, test the result, and present limitations.

## Recommended workflow

1. Write a one-paragraph problem statement and success criteria.
2. Inspect the data, inputs, constraints, and risks before building.
3. Create the smallest working baseline.
4. Improve one decision at a time and record the evidence.
5. Test realistic and failure cases.
6. Present the result, limitations, and next improvement.

## Expected deliverables

- A reproducible project with clear setup instructions.
- A short explanation of the approach and important decisions.
- Evidence such as tests, metrics, screenshots, or sample outputs.
- A reflection describing limitations and what you would improve next.

## Practical activity

Select a metric before modeling, establish a baseline, compare models, and explain errors.

Before you finish, write down the input, expected output, assumptions, and at least two checks that would reveal an incorrect result.

## Common mistakes

- Allowing test information into training.
- Choosing a model before defining the metric.
- Reporting one score without error analysis.

## Key takeaways

- Class-Based Machine Learning Projects belongs to a larger workflow; understand both the technique and where it fits.
- Small, testable examples make assumptions and errors easier to see.
- A trustworthy result includes validation, interpretation, and clearly stated limitations.
