# AI & Data Science Learning Path

Welcome to a **10-month, beginner-to-advanced learning program** covering Python, data analysis, statistics, machine learning, deep learning, MLOps, big data, generative AI, and agentic AI.

No advanced background is required. Basic programming experience is helpful, but the course begins with Python foundations and builds each skill progressively.

## How the book is organized

Every syllabus module appears as a module in the sidebar. Each distinct syllabus topic is a dedicated chapter, while class-based and home-based projects have their own project chapters.

| Module | Schedule | Focus |
| --- | --- | --- |
| 1. Python Foundations | Weeks 2–6 | Build the programming foundation needed for data science, machine learning, and AI development. |
| 2. Python for Data Science | Weeks 7–10 | Use NumPy, Pandas, and visualization libraries to prepare, explore, and communicate data. |
| 3. Statistics and Math for ML | Weeks 11–14 | Develop the mathematical intuition needed to reason about data and model training. |
| 4. Machine Learning | Weeks 15–21 | Build reliable supervised and unsupervised learning workflows from preprocessing through evaluation. |
| 5. Deep Learning | Weeks 22–26 | Learn neural-network foundations and apply them to images, text, and sequential data. |
| 6. MLOps | Weeks 27–30 | Move machine-learning systems from notebooks into reproducible, observable production services. |
| 7. Big Data and Cloud | Weeks 31–34 | Process data at distributed scale and understand the cloud services that support data and ML workloads. |
| 8. Generative AI | Weeks 35–38 | Understand modern language models and build grounded applications with prompting, adaptation, and retrieval. |
| 9. Agentic AI | Weeks 39–41 | Design AI systems that plan, use tools, retain useful state, and collaborate safely. |
| 10. Career Skills | Throughout the course | Turn technical learning into clear communication, a credible portfolio, and professional opportunities. |

## How to learn effectively

1. Read the learning objectives before starting a chapter.
2. Recreate examples instead of only reading them.
3. Complete the practical activity and write down assumptions.
4. Answer the review questions without looking back first.
5. Build the module projects and present what you learned.

## Course setup · Week 1

During the opening week, review course expectations and the roadmap, install Python, choose an IDE such as VS Code, and confirm you can run a Python file and a notebook.

~~~bash
python --version
python -m pip --version
~~~

:::tip Start with evidence
Keep every exercise and project in version control. A clear record of experiments, decisions, and improvements becomes part of your professional portfolio.
:::
